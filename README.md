# Calculadora React

Calculadora responsiva desenvolvida com React, HTML e CSS. O projeto organiza a interface em componentes para exibir valores e processar operações aritméticas básicas.

## Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Cálculo de porcentagem.
- Alternância de sinal.
- Limpeza dos valores.
- Entrada de números decimais.
- Layout responsivo e animações de interação.

## Tecnologias

- React
- JavaScript
- HTML
- CSS

## Organização

- **Calculadora:** mantém o estado e coordena a lógica das operações.
- **Display:** apresenta e formata o valor atual.
- **Botão:** componente reutilizável para números, operações e funções.

## Executar localmente

```bash
npm install
npm start
```

A aplicação fica disponível em [http://localhost:3000](http://localhost:3000).
